# frame-kunst

Achtergronden voor mijn Samsung The Frame (3840×2160).

- `schilderijen/` — de afbeeldingen; Home Assistant haalt ze op via de raw-link en zet ze in Art Mode
  (script `script.frame_toon_afbeelding`).
- `generator/paint.py` — de code waarmee de schilderijen procedureel gemaakt en met penseelstreken gerenderd zijn.
